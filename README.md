# SBlow Repo

Dépôt Sileo/Zebra pour les tweaks rootless de SBlow.

Source à ajouter dans Sileo : `https://rootatsblowfr.github.io/sileo/`

## Ajouter ou mettre à jour un tweak
1. Mets le `.deb` dans `debs/` (supprime l'ancienne version).
2. Ajoute ou mets à jour sa fiche dans `depictions/`.
3. Push sur `main`. Le workflow régénère `Packages` et `Release`, puis publie sur GitHub Pages.
